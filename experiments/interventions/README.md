# Group interventions (frozen pointers)

Per `experiment-protocol.md`, only these files differ between groups; the task body in `tasks/*.md` stays identical.

| Group | File | Role |
| --- | --- | --- |
| Baseline | `baseline.md` | No extra instructions beyond the task file. |
| Experience Skill | `experience-skill.md` | Operator enables project skill `frontend-productization` and follows routing (3–5 units). |
| Full Prompt | `full-prompt.md` | Operator pastes the frozen checklist from `experiments/full-prompt-checklist.md`. |

Record the chosen `intervention_path` in `experiments/run-log.csv` for each run.
